Project Objectives

The main objective of this project was to establish a functional virtual cybersecurity laboratory for practical learning.

Specific Objectives

1. Set up Oracle VirtualBox on Ubuntu.
2. Import and configure Kali Linux as a virtual machine.
3. Configure a NAT Network for virtual machine connectivity.
4. Test internet connectivity from Kali Linux.
5. Create a clean snapshot for recovery and future use.
6. Prepare a controlled environment for future cybersecurity and penetration testing exercises.

Expected Outcome

A working virtual lab environment that can be used to practise cybersecurity concepts and authorized penetration testing activities.
