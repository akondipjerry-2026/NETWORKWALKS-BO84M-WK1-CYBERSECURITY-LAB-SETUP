Operating System: Ubuntu Linux

1. Introduction

This project documents the setup of a virtual cybersecurity laboratory using Oracle VirtualBox and Kali Linux. The purpose was to create a controlled environment for learning cybersecurity and penetration testing.

2. Tools Used

- Ubuntu Linux (host operating system)
- Oracle VirtualBox
- Kali Linux 2026.3 (virtual machine)

3. Tasks Completed

- Installed and configured Oracle VirtualBox.
- Imported and configured the Kali Linux virtual machine.
- Created a NAT Network in VirtualBox.
- Connected the Kali Linux virtual machine to the NAT Network.
- Tested internet connectivity.
- Created a clean virtual machine snapshot.

4. Key Concepts Learned

- Virtual machines and virtualization.
- Differences between NAT and NAT Network.
- Virtual network configuration.
- Internet connectivity in virtual machines.
- Creating and restoring virtual machine snapshots.
- Importance of documenting technical procedures.

6. Conclusion

This project provided practical experience in setting up a virtual cybersecurity laboratory. It established a foundation for future hands-on cybersecurity and penetration testing exercises.
