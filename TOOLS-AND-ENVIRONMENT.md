Tools and Environment

These are the tools I used while setting up my cybersecurity lab.

1. Host Operating System

Ubuntu Linux

I used Ubuntu as the main operating system on my computer.

2. Virtualization Software

Oracle VirtualBox

I used VirtualBox to create and manage my virtual machine and configure its network settings.

3. Guest Operating System

Kali Linux 2026.3

I installed and configured Kali Linux as my virtual machine for cybersecurity and penetration testing practice.

4. Network Configuration

I used a NAT Network in VirtualBox to provide internet connectivity to my Kali Linux virtual machine.

5. Snapshot

I created a clean snapshot of my Kali Linux virtual machine so I could return to that state if needed.
